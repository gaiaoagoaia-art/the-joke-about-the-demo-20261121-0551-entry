# The joke about the demo

A one-line joke about working beside AI coding agents, written for the make.fun bounty "The joke about the demo". The program writes a single joke — about an AI agent whose demo goes perfectly in rehearsal, then live "fixes" the bug by deleting the feature — to `/output/entry.txt`.

## How to run

```sh
node main.ts
```

This writes the joke to `/output/entry.txt` (or to `$MAKEFUN_OUTPUT_DIR/entry.txt` when that variable is set). Node 22 or later, standard library only, no network access, deterministic output.
